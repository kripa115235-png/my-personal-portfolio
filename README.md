## About the Website

The portfolio website is designed as a simple and clean personal webpage. It uses HTML semantic elements such as `header`, `nav`, `main`, `section`, `article`, `form`, and `footer` to organize the content.

The website includes:

- **About Me** - A short introduction and profile photo.
- **Technical Skills** - HTML, CSS, JavaScript, Git, and GitHub.
- **Projects** - Information about my portfolio website and login/registration page.
- **Contact Me** - A form for name, email, and message.
- **Footer** - Copyright information.
